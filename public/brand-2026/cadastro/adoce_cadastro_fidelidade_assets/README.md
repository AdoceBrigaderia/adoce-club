# Adoce Brigaderia — Cadastro do cartão fidelidade

Assets recriados individualmente para o último mockup, sem recortar a imagem.
- `logo/`: logomarca original enviada pelo usuário, copiada sem redesenho.
- `decoracoes/`: ondas, chocolate, rabiscos, corações e fundo.
- `icones/`: SVGs independentes para campos e navegação.
- `estilos/`: CSS inicial e tokens visuais.
- `referencias/`: dependência da fotografia original da torta.

**Atenção:** são recriações vetoriais aproximadas, não equivalência pixel a pixel.
A logomarca preserva os pixels originais (inclusive eventual padrão quadriculado
embutido na imagem). Para transparência perfeita é necessário arquivo de logo
com alfa original.

A foto do produto NÃO foi recortada do mockup. Use a foto original do catálogo.
Não rasterize os textos, campos, botões, termos, links ou a navegação:
devem ser HTML/CSS e componentes funcionais.

Campos do formulário: nome, sobrenome, WhatsApp com DDD, senha e aceite.
Não há campo de e-mail. A redação aprovada usa sempre "cartão fidelidade".
Não implementar autenticação real apenas com este CSS.
