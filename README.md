# Adoce Club

PWA mobile-first para vendas e fidelidade da Adoce Brigaderia. O MVP inclui cliente, vendedor, administração, QR/token, cartão familiar, indicação e relatórios locais.

## Rodar

```powershell
npm install
npm run asset
npm run dev
```

Build: `npm run build`. Testes: `npm test`. Documentação: `npm run docs` e abra `Documentacao/Portal/index.html`.

O front usa estado mockado em memória. A estrutura futura do Supabase está em `supabase/`.
