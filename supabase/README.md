# Supabase

1. Crie um projeto privado no Supabase.
2. Execute `schema.sql`, `policies.sql` e `seed.sql` nessa ordem.
3. Configure `.env` a partir de `.env.example`.
4. Antes de produção, implemente RPCs transacionais para resgatar token, emitir carimbos/prêmio e liberar indicação.

O front atual usa mocks. Nenhuma chave real deve ser versionada.
